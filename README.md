# Jeopardy-Project
Repo for the Jeopardy CS project team


This year, you will be working on coding and implementing the game of Jeopardy using the skills you learned about HTML, CSS, and Javascript. The design team has laid out what how they want the Web App to look like, your tasks are as followed:
1) Develop the framework of the app using code to build out pages
2) Import and implement assets used by the Design Teams figma mockup
3) Make a functioning Jeopardy-styled game, using JS to switch between questions and answers.

This is the Figma Mockup for the Jeopardy Game [https://www.figma.com/design/er7XYIOZKJF3Qbt1QdW2sW/Jeopardy?node-id=0-1&t=MTOfF2FrvcgPW4kH-1]
There will be 4 branches to help manage the work. The main branch is where we will host all of the code, and the other branches will were each individual team member will do their changes.
